# EIROS MCP: независимое аварийное восстановление

При одновременной недоступности основного `EBRIDGE` и `Ebridge VPS Ops` не перезагружать VPS вслепую и не тратить время на бесконечные повторные вызовы MCP.

Существует резервный независимый маршрут на GitHub-hosted Actions, управляющий сервером через официальный Hetzner API. Его инструменты, подтверждения действий и диагностика находятся **только в приватном репозитории `ricobiz/eiros-agent-hub`**:

`docs/MCP_OOB_RECOVERY.md`

Аварийный путь использует подключённый GitHub MCP и не требует работающего туннеля EIROS. Он не активен для операций провайдера без отдельно настроенного GitHub Actions secret `HCLOUD_TOKEN`. Никогда не размещай токены в чате, исходниках или issue.

Отдельный приватный runbook включает безопасную проверку состояния и жёсткую защиту от случайного перезапуска общего многопроектного VPS.

Причина сбоя 2026-10-16 окончательно не установлена: публичный VAULT API отвечал, оба основных MCP канала — нет. После восстановления получить журналы и отладить маршруты туннелей.
